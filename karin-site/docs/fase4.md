# Fase 4 — Tráfego Pago (escala)

Escopo: fora do repo. Só rodar **depois** Fase 1 + 2 + 3 prontos (sem funil, ads queima dinheiro).

## Pré-requisitos
- [ ] Site convertendo (Fase 1 done)
- [ ] Meta Pixel + GA4 validados com eventos
- [ ] Lead magnet funcional
- [ ] WhatsApp com pré-qualificação (Fase 3)

## Tarefas

### 4.1 Estrutura de conta Meta Ads
- [ ] BM + conta de anúncios
- [ ] Pixel + Conversions API (CAPI) — iOS 14+ mata só Pixel
- [ ] Eventos customizados: `Lead` (download guia), `Contact` (click WhatsApp), `Schedule` (agendou)

### 4.2 Campanhas (3 iniciais)
- [ ] **Ansiedade** — público: mulheres 25-45, interesses saúde mental
- [ ] **Insônia** — público: 30-55, interesses sono/bem-estar
- [ ] **Burnout** — público: 28-45, interesses produtividade/trabalho

### 4.3 Criativo
- [ ] Vídeo vertical 15-30s com Dra falando (não stock)
- [ ] 3 variações por campanha (A/B/C)
- [ ] Hook nos 3 primeiros segundos
- [ ] CTA claro: "Baixe o guia gratuito" OU "Agende pelo WhatsApp"

### 4.4 Destino
- [ ] Landing dedicada por campanha (não home) — reusa seções do site
- [ ] Todas com UTM: `utm_source=meta&utm_campaign=...&utm_content=...`

### 4.5 Orçamento + otimização
- [ ] Budget teste: R$ 30-50/dia por campanha, 7 dias
- [ ] Matar criativo com CPL > target após 100 impressões sem lead
- [ ] Escalar ganhador +20%/dia

### 4.6 Métricas-alvo
- [ ] CPL (custo por lead) — definir target após baseline
- [ ] CPA (custo por agendamento)
- [ ] ROAS (receita / gasto) — meta inicial: 3x

## Critério de done
3 campanhas rodando, CPA dentro do target, dashboard com CPL/CPA/ROAS atualizado semanal.
