# Fase 3 — Instagram + WhatsApp (conversão)

Escopo: fora do repo (operação). Spec para execução.

## Tarefas

### 3.1 Bio Instagram
- [ ] Reescrever bio:
  ```
  Psiquiatra CRM SC XXXXX
  Ansiedade • Insônia • Depressão
  Atendimento online e presencial
  ⬇️ Agende sua consulta
  ```
- [ ] Link único → site (não WhatsApp direto; usar site como hub com pixel)
- [ ] Destaques organizados: Sobre, Depoimentos, Perguntas, Agendar

### 3.2 Funil de conteúdo (estrutura fixa)
- [ ] **TOPO (atração)** — 40% dos posts: "3 sinais que sua mente está sobrecarregada", "Você sente isso?"
- [ ] **MEIO (autoridade)** — 40%: explicações educativas, mitos x verdades
- [ ] **FUNDO (conversão)** — 20%: "Se você se identificou, posso te ajudar" + CTA

### 3.3 Formato
- [ ] Reels 15-30s (prioridade — maior alcance)
- [ ] Frases-gancho fortes: "Você não está cansada. Você está esgotada emocionalmente."
- [ ] Todo post tem CTA no fim (comentário, salvar, DM, link bio)

### 3.4 WhatsApp — pré-qualificação automática
- [ ] Usar Zapy/ZyraChat (stack já dominada)
- [ ] Fluxo de entrada:
  1. "Oi, vi que você quer ajuda. Posso te explicar como funciona a consulta?"
  2. "Qual sua principal queixa? (ansiedade / insônia / depressão / outro)"
  3. "Há quanto tempo sente isso?"
  4. "Já fez tratamento antes?"
- [ ] Roteamento: lead qualificado → secretária; não-qualificado → nutrição
- [ ] Follow-up automático: D+1, D+3, D+7 se não agendou

### 3.5 Métrica
- [ ] Taxa resposta → agendamento
- [ ] Origem do lead (UTM ou tag no fluxo)

## Critério de done
Bio otimizada, 10 conteúdos publicados seguindo funil, fluxo WhatsApp rodando com pré-qualificação + follow-up.
