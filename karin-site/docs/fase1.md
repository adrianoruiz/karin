# Fase 1 — Site: Conversão (prioridade máxima)

Escopo: karin-site. Meta: transformar site de cartão de visita em máquina de agendamento.

## Tarefas

### 1.1 Posicionamento / Nicho
- [ ] Decidir nicho: "Psiquiatra para mulheres com ansiedade e sobrecarga emocional" **OU** "Especialista em ansiedade e insônia"
- [ ] Aplicar nicho escolhido em: hero, meta title, meta description, OG tags

### 1.2 Hero Section
- [ ] Trocar headline atual por dor-específica. Ex: "Pare de viver no automático. Ansiedade, insônia e exaustão têm tratamento."
- [ ] Subheadline com credencial (CRM SC + especialidade)
- [ ] CTA primário: botão grande "Agendar consulta agora (WhatsApp)" → link `wa.me` com mensagem pré-preenchida
- [ ] CTA secundário: "Baixar guia gratuito" (lead magnet)
- [ ] Foto profissional da Dra acima da dobra

### 1.3 Prova Social
- [ ] Coletar 5-10 depoimentos reais (texto ou print anonimizado)
- [ ] Criar seção "Resultados de pacientes" com: "voltei a dormir", "reduzi ansiedade"
- [ ] Adicionar selos: CRM, formação, tempo de atuação
- [ ] Contador: X pacientes atendidos / Y anos de experiência

### 1.4 Lead Magnet
- [ ] Escrever PDF "7 sinais de ansiedade que você está ignorando"
- [ ] Criar landing/seção com form: nome + WhatsApp + email
- [ ] Integrar captura com ferramenta (RD Station / Mailchimp / n8n → WhatsApp)
- [ ] Email/WhatsApp automático entregando PDF
- [ ] Sequência de nutrição: 3 mensagens (dia 1, dia 3, dia 7) → CTA consulta

### 1.5 WhatsApp Integration
- [ ] Todos CTAs apontam para `wa.me/55XXXXXXXXX?text=...`
- [ ] Mensagem pré-preenchida por origem (hero, footer, blog) para rastreio
- [ ] Botão WhatsApp flutuante em todas páginas

### 1.6 Medição
- [ ] GA4 + Meta Pixel instalados
- [ ] Eventos: `click_whatsapp`, `download_guia`, `submit_form`
- [ ] UTM em todos links externos (IG bio, ads)

## Critério de done
Site publicado com: novo hero, prova social, lead magnet funcional, WhatsApp rastreado, analytics validado.
